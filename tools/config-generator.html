Ubuntu 24.04 · PHP application server provisioning

server-setup.conf generator

Fill in the fields below to produce a ready-to-use server-setup.conf for the magento-server-setup repo. It's framework-agnostic — the server it provisions works for Magento, WordPress, Drupal, or any other PHP application. Every version and every optional service is a dropdown or a switch below; nothing you type is uploaded, logged, or sent anywhere.

Identity

Database
Install a database
Turn off for a static site or an app using an external/managed database.

MySQL 5.6/5.7 are end-of-life and no longer in Oracle's apt repo for Ubuntu 24.04, so the setup script installs these two via an auto-provisioned Docker container (official image) instead of natively — the only place this toolchain depends on Docker. Use 8.0 or 8.4 unless you have a specific legacy reason to pick an older series.

Access & credentials

SSH keys are the public half only — never paste a private key here. Root and the application user each pick key or password independently — the application user always gets an unprivileged shell plus su - access from root.
